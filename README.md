# i3 Dotfiles

A minimalist and productivity-focused i3wm setup for EndeavourOS.

## Preview

![Desktop](screenshots/desktop.png)

## Features

* i3 Window Manager
* Polybar
* Picom compositor
* Tokyo Night inspired theme
* Vim-style navigation (hjkl)
* Scratchpad support
* Bluetooth manager shortcut
* Kali Linux VirtualBox launcher
* Lightweight setup (~900MB RAM idle)

## Applications

* URxvt
* Kitty
* Rofi
* Thunar
* Flameshot
* Blueman
* Spotify
* VS Code

## Keybindings

| Shortcut          | Action              |
| ----------------- | ------------------- |
| Super + Enter     | URxvt               |
| Super + T         | Kitty               |
| Super + W         | Chrome              |
| Super + D         | Thunar              |
| Super + C         | VS Code             |
| Super + N         | Blueman             |
| Super + Shift + O | Start Kali Linux VM |
| Super + S         | Rofi                |

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/i3-dotfiles.git
cd i3-dotfiles
chmod +x scripts/install.sh
./scripts/install.sh
```
